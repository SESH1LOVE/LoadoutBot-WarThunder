# «ьшп 21 пфм»: как я учил бота понимать, на какой технике зритель просит сыграть

> Стримеры War Thunder принимают заказы техники за донаты. Зрители пишут названия машин как угодно: в падежах, с опечатками, русскими буквами вместо латинских и в другой раскладке. Как сделать распознавание 3 028 машин без нейросетей — на склейках слов, нескольких «прочтениях» и расстоянии Дамерау — Левенштейна.

## Задача

На стримах War Thunder есть формат «заказ техники»: зритель донатит и пишет, на чём стример играет следующий бой.
Я делаю LoadoutBot — программу, которая читает донаты из DonationAlerts и DonatePay и сама ведёт очередь таких заказов.

Подключить донаты оказалось просто. Сложно — понять, что написал человек. В игре 3 028 машин, и вот как их называют
в донатах:

| Написал зритель | Имел в виду |
|---|---|
| закажу миг 21 пфм | МиГ-21ПФМ |
| р51д 30 | P-51D-30 |
| ьшп 21 пфм | МиГ-21ПФМ (не та раскладка) |
| ешпук р1 | Tiger H1 (вся фраза в другой раскладке) |
| на мессере г6 | Bf 109 G-6 |
| спитфайр мк 9 | Spitfire Mk.IX |
| на тигре е | Tiger E |
| миг 21 пвм | МиГ-21ПФМ (опечатка) |

И главное требование: **лучше не угадать, чем угадать неправильно.** Если стример сыграет не на той машине, за которую
заплатили, это хуже, чем вопрос «какой именно?». Поэтому спорные случаи бот не решает сам, а откладывает «На проверку»
с вариантами.

## Шаг 1. Канон: всё приводим к латинице без знаков

И названия машин, и сообщение приводятся к одному виду — латиница в нижнем регистре, без пробелов и знаков:

```
«МиГ-21 ПФМ»      → mig21pfm
«ф104г»           → f104g
«Spitfire Mk IX»  → spitfiremk9
```

Транслитерация кириллицы, затем «фонетическое» сглаживание, чтобы английское и русское написание сходились:

```js
function phonetic(s) {
  return s
    .replace(/sch/g, 'sh')   // Messerschmitt → messershmit
    .replace(/ph/g, 'f')     // Phantom → fantom
    .replace(/kh/g, 'h')
    .replace(/w/g, 'v')
    .replace(/([a-z])\1+/g, '$1');   // двойные буквы: ss → s
}
```

Римские цифры приводятся к арабским: «Mk IX» = «мк 9». Одиночные I, V, X считаются цифрой только после «Mk/Mark» —
иначе «V» в обычном слове превратилась бы в пятёрку.

## Шаг 2. Склейки соседних слов

Сообщение режется на слова, и проверяются склейки из 1–4 соседних слов — на **точное** совпадение с каноном названия.
«миг 21 пфм» даёт склейки `mig`, `mig21`, `mig21pfm`, `21pfm`… — и `mig21pfm` совпадает с названием.

Почему не искать подстроку во всём сообщении? Потому что случайные буквы внутри обычных слов дают ложные совпадения:
в «спасибо за стрим» найдётся что угодно. Склейка целых слов — гораздо надёжнее.

Отдельная ловушка — вложенные совпадения. В «су 25 т» есть и «су 25», и «су 25 т». Совпадение, целиком вложенное
в более длинное совпадение другой машины, отбрасывается: зритель имел в виду Су-25Т.

## Шаг 3. У каждого слова несколько прочтений

Здесь основная магия. Для каждого слова сообщения строится несколько вариантов:

1. **Обычная транслитерация:** «миг» → `mig`.
2. **Похожие буквы:** кириллица, которая выглядит как латиница, — так часто набирают P-51, B-17, T-80:
   ```js
   const LOOKALIKE = { а:'a', в:'b', е:'e', к:'k', м:'m', н:'h', о:'o', р:'p', с:'c', т:'t', у:'y', х:'x' };
   ```
   «Р-51» → `p51`, а не `r51`.
3. **Не та раскладка:** ЙЦУКЕН ↔ QWERTY по позициям клавиш. «ьшп» → `mig`, «vbu» → «миг» → `mig`.
4. **Падежи:** «на мустанге» → мустанг, «на тигре» → тигр, «на сушке» → сушка.

Склейки строятся по всем прочтениям сразу, поэтому «р51д 30» находит P-51D-30, хотя ни одно слово само по себе
не совпадает с названием. Чтобы комбинаций не стало слишком много, на каждом шаге склейки хранится не больше 64 вариантов,
а склейка запоминает, взяла ли она «неосновное» прочтение: при споре выигрывает совпадение по обычному чтению.

Отдельный случай — **вся фраза в другой раскладке**: «ешпук р1». По словам это не ловится: «р1» — слишком короткий кусок.
Поэтому сообщение целиком переводится в другую раскладку и ищется ещё раз. Перевод берётся, только если он дал точное
совпадение и оно полнее найденного: «ешпук р1» — это Tiger H1, а не вертолёт «Tiger». Обычный русский текст
после перевода раскладки превращается в бессмыслицу и ничего не находит — ложных срабатываний нет.

## Шаг 4. Прозвища

Зрители пишут «фантом», «мессер», «сушка», «тридцатьчетвёрка». Прозвища хранятся как правило «регулярка по названию →
список прозвищ» и работают двумя способами:

- **вместо части названия:** «мессер ф4» → Bf 109 F-4, «фантом е» → F-4E;
- **сами по себе:** «фантом» → все F-4 на выбор. Это как раз случай «не угадываем»: F-4 в игре десяток,
  бот отдаёт донат стримеру «На проверку» с вариантами.

Часть прозвищ генерируется автоматически (например, английские названия «на слух»: «файрфлай»), часть написана руками.
Ручные весят чуть больше: при споре побеждают они.

## Шаг 5. Опечатки — но не в цифрах

Если точного совпадения нет, ищется название с опечаткой в 1–2 буквы — расстояние Дамерау — Левенштейна
(Левенштейн плюс перестановка соседних букв: «мги» → «миг» — это одна ошибка, а не две).

Правило, без которого всё сломалось бы: **цифры должны совпадать.** «миг 23» никогда не станет «миг 21».
Для этого ключи для нечёткого поиска заранее сгруппированы по цифрам внутри названия: ищем только среди названий
с теми же цифрами.

Перебирать 3 028 машин на каждый донат расточительно, поэтому кандидаты отсекаются дёшево ещё до расчёта расстояния:

- по длине — опечатка в 1–2 буквы меняет длину не больше чем на 2;
- по набору букв — битовая маска 26 бит: одна опечатка меняет набор не больше чем на 2 буквы, поэтому ключи
  с сильно другим набором отбрасываются без расчёта.

```js
function letterMask(s) {
  let m = 0;
  for (let i = 0; i < s.length; i++) {
    const c = s.charCodeAt(i) - 97;
    if (c >= 0 && c < 26) m |= 1 << c;
  }
  return m;
}
// popcount(maskA ^ maskB) > 2 * limit → точно не подходит
```

Плюс ранний выход в самом Дамерау — Левенштейне: если минимум в строке матрицы уже больше лимита — дальше не считаем.

## Шаг 6. Одинаковые названия у разных машин

«ИС-2» есть у СССР и у Китая, «Т-80У» — у СССР и у Швеции. Это разные машины с одним написанием, и их нельзя склеивать.
Выбирать помогают подсказки:

- **нация в сообщении:** «китайский ис 2», «т-80у швед»;
- **БР в сообщении:** «т-80у 11.7»;
- **ангар стримера:** что у него вообще есть;
- **память выбора:** как стример решил в прошлый раз.

Слово нации само по себе заказ не создаёт: «привет из Германии» — это не заказ.

## Что получилось

- Распознавание работает целиком на компьютере стримера, без сервера и нейросетей, за миллисекунды.
- Спорное не угадывается: несколько вариантов, нехватка денег, техника, которую стример не принимает, — всё уходит
  «На проверку» с причиной.
- Тесты — это просто таблица «сообщение → ожидаемая машина или список вариантов». Каждый странный донат из жизни
  становится новой строкой в тесте.

Список техники и БР обновляется после патчей из открытого датамайна игры, прозвища пересобираются автоматически.
