# Бесплатный оверлей очереди для OBS: шпаргалка

Оверлей очереди — небольшой блок поверх игры: что играем сейчас, кто заказал, сколько осталось и кто следующий.
Он снимает вопросы «а мой заказ где?» и показывает новым зрителям, что заказы у вас есть.

Полная статья со всеми стилями — на сайте: [Бесплатный оверлей очереди для OBS](https://loadoutbot.ru/blog/overlay-ochered-obs.html?utm_source=github&utm_medium=guide).

## Что должно быть на оверлее

| Элемент | Зачем |
|---|---|
| Текущая машина и ник зрителя | Заказчик видит, что играют его заказ |
| Прогресс «фраги 2/3 · бои 1/2» | Нет споров, выполнено или нет |
| Следующие 3–5 заказов с номерами | Каждый видит своё место. Больше не нужно — длинный список закрывает игру |
| Строка с ценами | «Заказ техники от 300 ₽ · 3 фрага или 2 боя» — новые зрители сразу понимают формат |

## Добавить в OBS за минуту

1. [Установите LoadoutBot](ustanovka.md) — бесплатно, без регистрации.
2. В панели бота: «⚙️ Настройки» → «📺 Стрим и OBS» → скопируйте адрес оверлея (`http://localhost:3000/overlay`).
   `localhost` значит «этот компьютер» — из интернета адрес не виден.
3. OBS → «Источники» → «+» → «Браузер» → вставьте адрес.
4. Размер: **460 × 520**. Для «Бегущей строки» — 1400 × 80, для «Строки» — 700 × 50.
5. Перетащите источник на место. В панели бота появится «✓ OBS видит оверлей».

Стиль меняется в панели одной кнопкой — адрес в OBS менять не нужно.

## Где расположить в War Thunder

По углам экрана у игры важное: миникарта, чат, счёт, информация о технике. Выберите место, которое в вашем режиме
ничего из этого не закрывает, и проверьте на записи. Меньше всего перекрывают стили без фона.

Многие смотрят стримы с телефона: если текст мелкий, увеличьте масштаб адресом (`?scale=1.3`), а не растягивайте
источник в OBS — так буквы останутся чёткими.

## Полезные параметры адреса

Можно сделать несколько источников с разным видом:

| Параметр | Что делает |
|---|---|
| `?style=glass` | Свой стиль только для этого источника |
| `?view=current` | Только текущая машина, без очереди |
| `?scale=1.3` | Крупнее без потери чёткости |
| `?rules=0` | Без строки с ценами |

## Оверлей не появляется в OBS

| Что видно | Что сделать |
|---|---|
| Пустой источник | Бот не запущен — откройте LoadoutBot, затем в OBS правой кнопкой по источнику → «Обновить» |
| В панели нет «✓ OBS видит оверлей» | Проверьте адрес: `http://localhost:3000/overlay`, без лишних пробелов |
| Оверлей обрезан | Ширина и высота источника меньше нужных — верните 460 × 520 |
| Чёрный фон вместо прозрачного | В свойствах источника «Браузер» очистите поле «Пользовательский CSS» от своего фона |
